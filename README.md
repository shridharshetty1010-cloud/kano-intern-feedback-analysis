# Kano Analysis of Intern Feedback

## Project Overview
This project was developed during my Business Analytics Internship at Zephyr Technologies & Solutions Pvt. Ltd. to evaluate intern satisfaction and identify key factors influencing the internship experience using the Kano Analysis framework.

The project involved collecting survey responses, cleaning and analyzing the data using Python, and building an interactive Power BI dashboard to visualize satisfaction trends and actionable insights.

## Objective
To assess intern satisfaction levels and categorize feedback using Kano Analysis in order to identify:
- Must-have expectations
- Performance factors
- Delight factors
- Areas needing improvement

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Power BI
- Google Forms
- Business Analytics Frameworks

## Project Workflow
### 1. Data Collection
- Designed and distributed survey questionnaires to interns/students.
- Collected structured feedback data using Google Forms.

### 2. Data Cleaning & Processing
- Cleaned missing/inconsistent responses using Python.
- Structured survey data for analysis.

### 3. Exploratory Data Analysis
Analyzed:
- classroom facilities feedback
- teaching quality ratings
- supervisor ratings
- support/transition program effectiveness
- relevance of course materials
- internship duration feedback

### 4. Data Visualization
Built interactive Power BI dashboards to visualize:
- satisfaction distribution
- supervisor performance comparisons
- course/internship feedback trends
- category-wise feedback analysis

## Key Outcomes
- Identified major drivers of intern satisfaction.
- Highlighted improvement opportunities in support systems and learning experience.
- Transformed raw survey responses into actionable business insights.

## Business Impact
This project demonstrates how customer/intern feedback can be converted into strategic insights using business analytics, helping organizations improve experience design and decision-making.
